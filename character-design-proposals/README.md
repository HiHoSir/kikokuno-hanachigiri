## 不変要素

- 主人公：緋月（18歳）。水色のショートボブ、青い瞳、額中央に金色の角1本。
- 基本デザインは左右対称。装飾の左右差は原則なくす（ポーチ含め要検査）。
- 女性らしさと運動性を両立。華美な振り袖や長い垂れ布で動きを妨げない。
- 刀・脇差、歩行・走行・術・被弾・勝利など既存の8方向アニメのシルエットを考慮する。
- 現行V35の基準セルは80×112px。実際の動作セルはさまざまであり、検証画像にある小さなSD見本の「32px」は**第二作の採用サイズではない**。
- 試作の画像は衣装の構想図であり、既存3Dモデルへそのまま適用可能／モーションが破綻しないことを保証しない。

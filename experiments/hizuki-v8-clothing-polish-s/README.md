# 緋月V8 衣装の色面整理 R → S

[8方向の待機・歩行・走行をR/S比較する実験ページ](https://hihosir.github.io/kikokuno-hanachigiri/experiments/hizuki-v8-clothing-polish-s/)

- **画像生成なし、幾何変形なし。** 元のR版64×96pxのPNGを直接画像処理。拡大縮小、頭身・ポーズ・輪郭・透明背景・フレーム順に手を加えない。
- 各コマの上52行（顔・髪・装飾）は完全固定。衣装の赤・白・紺の近似色を素材別に共通パレットへ整理し、同素材の近傍画素だけで孤立する陰影を慎重に整理。
- 全9動作×8方向、計520コマを変換。透明ピクセルのビット単位一致をチェック済み。
- Pages版はR/S各24シート（待機・歩行・走行8方向ずつ）計48シートをHTML内へ埋め込み。静止・コマ送り・方向選択・再生速度変更が可能。
- 色面整理が最終的な「テイルズ オブ エターニア風」の美術承認を意味するわけではない。改変部分を比較して採否判断するための試作。
- 完全再生成用Pythonスクリプト、入力のR ZIP、S全72枚、GIF、検査レポートはチャットの実験ZIP `hizuki_v8_clothing_polish_S.zip` に収録。
- 本編への実装は未実施。

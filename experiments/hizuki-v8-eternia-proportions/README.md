# 緋月V8：エターニア寄り「右向き歩行8コマ」頭身実験

公開: https://hihosir.github.io/kikokuno-hanachigiri/experiments/hizuki-v8-eternia-proportions/

- **画像生成なし**。V8トゥーンレンダリングの256×256px×8コマから決定論的に64×96pxへ変換。
- 旧Bを元画像画素のまま保存。新E・FはBの画素を単純に引き伸ばしたものではなく、**同じ256pxの原画から再変換**。
- 旧B: 0.38倍・48色。
- E: カメラ相当の縮尺を0.43倍へ（約13%拡大）、頭部のみ局所的に10%強調、共通33色パレット＋輪郭線。
- F: 同縮尺、頭部を16%強調、RGBは最近傍サンプリング＋共通パレット。
- 8コマで同一処理・共通ピボット（256px原画の128,245→64×96画面の32,94）。コマ単位でトリミング・中央寄せなし。
- 全8コマに透明/不透明の二値アルファ、画像端への接触なし。各コマのアルファは原3Dに基づく。**E/Fは意図的に頭部を変形させるため、Bと輪郭が完全一致するものではない**。
- 右向きのみ試作。他7方向、待機、走行との頭身の整合は未検証。
- プレビューは B/E/F同期再生、停止・コマ送り、再生速度、1/1.2/2/2.7倍、右方向へ滑らかな連続移動（マス目移動なし）。
- 元の元画像、B基準画像、E/F再現スクリプト、差分とQAはこの会話の `hizuki_v8_eternia_rightwalk_reproducible_v1.zip` に収録。本編には反映していない。

**評価ポイント**：静止画の見た目だけでなく、足の交互接地、頭の揺れ、ループのつなぎ目を1.2倍・8fpsで確認する。

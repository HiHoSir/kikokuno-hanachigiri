# 作品別設定の作り方

**コアは作品非依存、設定は作品ごとに持つ。** サンプルの64×96や青/赤/紺パレットは実装要件ではなく単なる設定例。

| 項目 | 作品側で決めること |
|---|---|
| `target_width`, `target_height` | 例 32×32 / 48×64 / 64×96 / 80×120 |
| `alpha_threshold`, `margins` | 入力の透過品質と余白 |
| `source_map` | 方向・ポーズIDから原画へのパス |
| `palette` | キャラクター／オブジェクト固有の配色 |
| `protected_regions` | 顔・手・武器・足元などの矩形/マスク |
| `symmetry_policy` | 反転可能な方向と左右差の扱い |
| `approval` | 各方向の採用/候補/未制作 |

`examples/project_profile.json` は、作品がこの表をどう記録するかの構造例。CLIの `--width/--height` などへ必要値を指定する。CLIはこのJSONを自動読み込みしない（意図しないワークフローの自動適用を防ぐ）。

### 特に注意する例
- **緋月の一本角**や花飾り、左右対称は緋月のプロファイルに属する。
- **NPC**：色、頭身、服装、影処理は別プロファイル。
- **アイテム**：地面の接地位置は不要なことがある。`--margin-bottom` をゼロにしてもよい。
- **タイル/背景**：シルエット抽出だけではシームレス接続やレイヤー順序は作れない。タイル専用の追加仕様・QAが必要。
- **アニメ**：フレーム間の足位置・接地・左右腕の連動は本スキルの画像単体QAとは別にチェックする。

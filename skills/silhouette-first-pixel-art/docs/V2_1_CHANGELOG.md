# v2 → v2.1 変更履歴

- 複数方向の総色/共通色、意味部位別のパレット比較レポートを追加。無条件の共通色増加を目標としない。
- `protected` と `editable_parts` を矩形・多角形・画像マスクで定義し、差分パッチ適用時に強制。
- パッチに `viewId` / `partId` を追加可能。ガードを有効にした場合はこれらのメタデータを必須とし、コマ・部位の誤適用を拒否。
- 方向ごとの足元などの注釈と装飾の可視状態を明示的なルールと照合。見た目や手の向きを自動理解できると主張しない。
- 汎用v2 `draft` / `inspect` / `atlas` / `make-patch` / `apply` の元のCLI互換を保持。
- 構造/ポーズ矛盾の検査と美術的承認の分離を強化。
- 追加テストでは間違った方向、部位、保護顔、保護PNGマスク、領域外変更、alpha変更、パレット強制違反、注釈不一致を拒否する。

# 失敗事例（他作品にも共通）

- **出典の取り違え**：似た見た目の別原画を入力にした。→ソースSHAと方向を最初に確定。
- **最終カラーを単純Nearestで縮小**：目や模様が潰れる。→二値マスクだけ最近傍、色面は描き直す。
- **図形で人物を再構築**：原画の比率から外れる。→シルエット固定で始める。
- **自動色分離の誤認識**：髪の青と虹彩の青を混ぜ、目を損傷。→部位マスク/保護領域と目視QAを必須化。
- **無差別な色ノイズ除去**：花芯や髪先も消す。→描き込みは限定領域だけ。
- **ポーズや手の向きを勝手に変更**：正面と背面で手の甲/ひらの対応が破綻。→解剖学・承認原画を保持。
- **差分履歴の不一致**：別段階へパッチを適用し、結果が偶然似た画像になる。→SHA、beforeRGBA、依存関係を強制検査。
- **透過と絵の採用を混同**：alpha一致でも美術的に不自然。→機械合格と視覚承認は別。
- **固定サイズ・方向数の押し付け**：対象ゲームと設計が噛み合わない。→プロファイルで設定し、実装側へ固定しない。
- **背景が透過していない**：マスクが一枚の四角になる。→opaque coverageの検査と原画の修正。

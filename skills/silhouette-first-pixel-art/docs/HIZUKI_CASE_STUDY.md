# 事例：『鬼哭の花契り』緋月

この共通スキルの開発元となった実験。**汎用スキルを使う際に必須ではない**。

- 作品の参照5方向を使用。正面だけ頭身が合わなかったため最終候補から除外。
- 元の実験用キャンバスは64×96px。黒塗り二値マスクだけをNearest変換し、原画の色面ガイドと座標編集を組み合わせた。
- 修正の履歴（実験01〜05）には**作品固有の色・座標・方向・承認判断**が含まれる。ほかのキャラへ流用しない。
- 実験04は斜め前の座標指定135画素。実験05はほか3方向。**実験03は下半身の画素も一部変更した**ので「全段階で下半身不変」は誤り。
- 元実験のRGBA完全再現は別パッケージ `hizuki_pixel_skill_v1.zip` に保存されている。**この汎用パッケージには緋月原画・旧パッチを混ぜない。**

各作品はこのような `project-profile.json`、原画、diff履歴、成功/失敗ログを個別に持ち、スキル本体は共有する。


## 実験06のv2.1検査（実例・コア処理ではない）
RGBA PNG 4方向64×96を入力として検査。**総色42色、全方向共通34色**、4画像の不透明画素の最下部 y=94 に一致。これは塗りの品質や正しい足首/接地面を保証しない。観測された最下部alpha位置と、実際の接地ランドマークは区別する。実データの部位マスクは未付与であり、髪色などの材質別の厳密比較や手の向きの自動検査は**未実施**。

数字の検査レポートは `examples/hizuki-exp06-audit-summary.json` に収録するが、緋月の元画像/アセット/座標は汎用スキルのサンプルに混入しない。

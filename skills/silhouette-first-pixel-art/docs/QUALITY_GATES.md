# 品質ゲート

**Gate A: 入力の同一性** — 承認原画のSHA、方向ID、ポーズ、alphaと出典を確認。別キャラへのすり替え、無断ポーズ変更を拒否。

**Gate B: 形状** — 作成したアルファマスクが二値、目標W×H、縦横比維持、余白・接地面が意図通り。輪郭の形を原画と視覚比較。

**Gate C: 画素** — パッチには原RGBA SHA、x/y、before、rgbaが含まれる。適用前にbefore実値と範囲を検証。重複座標と古いSHAは拒否。パッチ適用結果と編集済みPNGの全RGBAバイトを照合。

**Gate D: 保護部** — 原則alpha変更=0（シルエットを変える場合は別候補・別承認）。目、装飾、手の向き、地面に接する靴、固定行など作品設定で保護し、差分数0を確認。`inspect --protect-bottom N` は最下N行の変更**数を報告するだけ**。合否判断は呼び出し側で実施。

**角落としの追加検査（任意工程）** — [CORNER_TRIMMING](CORNER_TRIMMING.md) の削除座標を事前に限定する。外周は選んだ画素の `255→0` と透明RGBの0化だけ、その他の画素はRGBA不変、保護領域差分0、接地・アンカー・キャンバス不変、再適用後の全RGBA一致を確認する。内部の色境界を整える工程はalpha差分0。穴・孤立ドット・1pxの細線切れ・輪郭線の欠けが生じていないかを実寸と整数倍で目視し、アニメは連続再生で輪郭のちらつきも検査する。`--allow-alpha-change` 自体は「安全な角削除だけ」を判定しない。

**Gate E: アート品質** — 原画と同じ人物/ポーズに見えるか、色面が読めるか、描き込みが眼・指をつぶしていないか。実寸と整数倍の両方で確認。数字は美術承認の代わりにならない。

**Gate F: 出力** — 作品が定めたサイズ・方向順・パレット・透明PNGを保持。アトラスはすべて同一セルサイズに限る。未作成フレームを勝手に埋めない。

## トラブル時
- アルファが変わった→上書きしない。別案へ分岐。
- 原画に背景やグロー→入力を修正してから再作成。
- `base SHA mismatch`→異なる版へ誤適用しない。元PNGを探す。
- 色面が汚い→自動減色を繰り返さず意味別に再描画。
- 横向きの腕が見えない→構造・オクルージョンを参照する。色替えで手足を捏造しない。

## v2.1追加ゲート
**Gate G: 保護領域の強制** — 目・角・髪飾り・接地面など「触れてはいけない場所」はプロジェクト別の `generic-pixel-guard-v1` を使い、**保存前に拒否**する。`--guard` 未指定での従来CLIはこの保護を強制できない。

**Gate H: 複数方向の同一性** — `scripts/semantic_quality.py audit` で材質の色、足元の注釈、可視装飾の注釈を検査する。共通色の数は診断値。色が同じでもポーズ・前後関係は正しいと判定できないため、人間が別途原画比較を実施する。

**Gate I: アノテーション妥当性** — `parts` や `features` のラベルは人間/AIの入力であり、CLIは画像認識で証明しない。欠落は `unannotated_feature` として失敗、目視との矛盾は承認しない。

## ジグザグ陰影の比較ゲート

[専用手順](ZIGZAG_SHADING.md) に従い、alpha・保護領域・足元差分0とパレット集合の一致を確認する。元PNG・編集ガード・順序付きパッチ・参照PNGを保存し、再適用の全RGBA一致を検証する。再現成功と美術採用は区別し、影面積の変更やアニメ未確認を報告する。

# 別AIへの汎用引き継ぎ文

このZIPは、承認済み透明原画をドット絵へ変換・直接修正するための**作品非依存の制作スキル**です。`SKILL.md` → `README.md` → `docs/PROCEDURE.md` → `docs/QUALITY_GATES.md` の順に読んでください。

## 作業指示
1. まず `python scripts/test_pipeline.py` を実行して、機械的処理の健全性を確認してください。
2. ユーザーが与えた承認原画・目的解像度・方向・ポーズ・パレット・保護部位を作品プロファイルに記録。ユーザーが指定していない画像を黙って原画にしないでください。
3. alpha二値化→マスクだけNearest縮小→色位置のガイドを生成し、未承認の下書きとして保存。カラー最終画像のNearest縮小だけで完了にしない。
4. キャラクターの意味的な構造に従ってRGBを1px単位で描き直し、元の輪郭・ポーズ・接地位置を維持してください。画像生成による再描画は、ユーザーの明示許可がない限り修正工程では行わない。
5. `make-patch` と `apply` でRGBA全画素を再現し、alpha変更=0、保護領域の変更=0を検査してください。
6. 実寸と拡大の比較画像を作り、未承認状態を明記して評価を受けてください。ゲーム本編へ勝手に採用しないでください。

## 注意
初期色面は面積平均・パレット近似の自動ラフです。これを「1ドットずつAIが意図的に手打ちした」と偽らないこと。プレビューと手修正を明確に区別すること。緋月固有の名前・角・花飾り・サイズ・方向は、この汎用スキルの必須要件ではありません。


## v2.1 引き継ぎ追記
- `scripts/semantic_quality.py` と `scripts/test_semantic_quality.py` も読み、必ず一度テストする。
- 特定の方向/部位を描き直す場合、作品専用ガードを定義し `--view` / `--part` / `--guard` を指定する。
- 複数方向の検査は「総色/共通色」「材質ごとの色の違い」「宣言済み足元位置」「可視注釈の整合性」を分離。色の強制統一と人体の自動認識を混同しない。

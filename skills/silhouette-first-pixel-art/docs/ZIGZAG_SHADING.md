# ジグザグ境界によるピクセル陰影（任意の比較工程）

影の色面の境界に1〜2pxの食い込み・段差を置き、髪の束や布の折れ目を読ませる。エターニアの参考画像を使う場合も、画面の見え方を作画参考とし、原作の処理を解析・再現したとは主張しない。

## 作り方

1. 採用済みの通常版から別候補へ分岐する。寸法・方向・ポーズ・パレット・alpha・表示倍率・接地点を固定する。角落としは通常版までで済ませ、この工程ではalpha変更を許可しない。
2. 原画の光源・髪束・服の折れ目から影の面を決める。部位ポリゴン／マスクを注釈し、顔・目・角・花飾り・模様・手・靴・外周を保護する。材質色の一致だけで部位や腕の前後を推定しない。
3. 明部・中間・影をまとまった色面にする。影の上端を一律な長い直線にせず、髪の流れや折れ目に沿って1〜2px食い込ませ、2〜3px程度のまとまりで交互につなげる。大きさは今回の解像度の例であり、別解像度へ固定しない。
4. 全面を同じ周期でギザギザにせず、必要な境界に限定する。チェッカー模様の一括ディザ、全体へのノイズ、全ての段差の鋸歯化を避ける。細い暗線を足すだけでなく、影の色面としてつながっているかを確認する。
5. 髪と衣装など部位ごとに別パッチを作り、`--guard`・方向・部位を指定して順番に再適用する。パッチのSHA・変更前RGBAと、最終PNGの全RGBA一致を検査する。
6. alpha差分0、保護領域差分0、追加色0、同じキャンバス・接地点を確認する。同じ色数でも色の集合が変わっていないかを照合する。
7. 実寸・整数倍・同じ背景で通常版と比較する。境界が汚れや縞に見えないか、髪束・服・手の境目が読みやすいか、明暗の面積が適切かを判断する。影の面積や明暗も変えた場合は、境界のジグザグだけを比較したと報告しない。アニメは別途ちらつきを検査する。

## 同じ結果を再現するために残すもの

入力PNG、参照結果PNG、パレット、方向・フレーム・カメラ、足元アンカー、意味付けした編集マスクと保護マスク、順序付き差分パッチ、入力／出力RGBAハッシュ、再現コマンド、比較画像、未確認事項を一組にする。会話の説明やLibrary IDだけに依存せず、再現に必要な実ファイルを保存する。

新しいポーズを描く際は今回の座標やマスクを流用せず、共通の作画方針と材質パレットを引き継ぐ。全方向・歩行への採用は静止画の比較から自動承認しない。

## 今回の具体例

[緋月80×112pxの再現セット](../../../experiments/pixel-zigzag-v1/README.md) を使う。入力と2つのパッチを同梱し、外部生成なしで再現する。

```bash
# レポジトリルートから。Pillow / NumPy が必要。
python experiments/pixel-zigzag-v1/reproduce.py --output /tmp/hizuki-zigzag-replay
```

`paint_recipe.py` は今回の形状注釈と描画座標を保存した作画レシピ、`reproduce.py` は記録済みの結果へ厳密に戻すための再適用。汎用スキルは両者を区別する。

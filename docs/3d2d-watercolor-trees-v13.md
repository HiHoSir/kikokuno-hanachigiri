# 『鬼哭の花契り』水彩樹木差し替え v13

## 目的
利用者が提供した桜と広葉樹の**2枚の元画像**を、既存の歩けるv12 3D→2Dデモに組み込む。前回のように新しい村の一枚絵を生成して代替しない。

## 変更範囲
- 公開対象：`demo-3d2d-watercolor-trees-v13.html`
- 元画像：桜 `35631E84-4916-4EB4-AE9E-1555F947DC0F.jpeg`、広葉樹 `2CD4AD90-4180-44EB-A00F-E74B49009DC1.jpeg`（利用者提供）
- JPEGの白背景をRGBA透明化、元絵の色と筆致を維持。新規の画像生成なし。
- 桜の表示：457×420px、接地アンカー[218,415]、ワールド(10.9,7.2)
- 広葉樹の表示：390×390px、接地アンカー[189,385]、配置(2.3,12.0)/(9.45,13.5)
- 3本の描画を元足元位置のまま置換。衝突半径0.26m・独立接地影・足元ソート・経路探索は既存のまま。
- 「参考木 ON / 旧木」切替あり。家・道・地面・川岸・橋・草花・小物・領域・カメラ・ヒーロー共通モーションコードは不変更。
- これは**v12を継承した独立デモ**であり、メインゲームの`maps/village/map.json`へ採用済みという意味ではない。

## 制作の考え方
固定カメラの水彩立ち絵を2D看板（Billboard）として配置。樹木の新たな3D幾何の開発は停止。別途、原本のPNG、ソース画像、デモ制作スクリプトと既存v12のHTMLを会話添付ZIPに同梱。出力HTMLには表示用WebPを内蔵し、素材サイズ／アンカーをmanifestとして保存。

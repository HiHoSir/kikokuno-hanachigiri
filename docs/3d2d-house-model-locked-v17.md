# 鬼哭の花契り — 既存民家3Dモデルを使った構図固定・淡彩試作 v17

2026-11-04。**美術候補／独立デモであり、本編・マップ正式採用ではない**。

## 目的
AI画像生成で屋根・戸口の構図を変えてしまうことを避けるため、採用済みの3D民家モデルの投影を固定し、その画像を水彩調に仕上げて既存の歩けるv14 3D→2Dデモへ差し込む。

## 元の3Dモデル
- `authoring/3d2d-v7/source/build_assets.py` に民家形状の生成手順があり、`build_textured.py` でUVモデルと画面素材を出力。
- v7制作ZIPに実物 `hanachigiri-v7/assets/house.glb` と `house.png` を収録。確認したGLBは実3Dメッシュ。
- カメラは**平行投影、俯角40°、方位角35°、100px/m**（v7 `render-metadata.json`）。
- 出力画像461×397px、足元アンカー `[233.161,260.386]`。モデル・座標・輪郭とアルファは変更しない。

## v17
- v14にあった西側民家 `x=4.35,z=7.0` の外見だけ交換。
- 元のhouse.pngを色領域別に処理し、顔料色ムラ・屋根の淡彩色面・粒子を焼き付けた**独立したRGBAラスタ**を作成。別構図の新規AI生成画像ではない。
- 手前の階段と縁側、戸口、屋根外形、建物の足元基準を保持。画像の切り抜き/再センタリング/縦横変形はしない。
- `house_watercolor_v17.png` のアルファは出力元PNGと完全一致。
- 樹木3本（ユーザー提供水彩素材）、東の茶屋、橋・道・川、各設置座標、当たり判定は変更なし。
- 比較ボタン「民家：水彩／民家：従来」、フォーカス「民家に寄る」を実装。
- 比較デモ: `demo-3d2d-house-model-locked-v17.html`。mainビルド配信対象へ登録。
- 本編 `maps/village/map.json` と `assets/characters/` は非変更。

## 再生成・引継ぎ
会話添付 `hanachigiri_house_model_locked_v17_sources.zip` にGLB/元レンダリング/新RGBA/メタデータ/生成スクリプト/検査スクリプト/比較スクリーンショットを格納。
実行順: `python build_house_v17.py` → `python make_demo_v17.py` → `python smoke_v17.py`。ソース内の相対パスはZIP展開先に合わせること。

次の美術工程では、**固定投影された画像の構図を壊さず、材質ごとに生成・描画する**。生成画像の単体の見栄えだけでなく、戸口・屋根四隅・接地・遮蔽・緋月との縮尺を検証する。

# 『鬼哭の花契り』3D→2D板材UV方向修正（v5）

**状態:** 独立した操作可能デモ。既存本編`index.html`、`maps/village/map.json`、緋月V35の画像・移動設定は未変更。

## 原因と修正

v4の木目UVは木材の面に対してワールドX/Zの固定対応を使っており、Z方向に伸びる板材の木目が幅方向へ横切っていた。v5では**板の物理長手方向をUVのU方向へ対応**させる`board_grain_axis()`と`uv_wood()`を導入した。

- 和風民家・茶屋の縁側床板：Z方向に木目を揃える。元の屋根・壁・柱・木組みの配色は維持。
- 木橋の床板（22枚）：Z方向へ木目。木橋専用の明るい`wood_deck`テクスチャを使用し、板の継ぎ目が消えないよう薄い立体目地21本を設置。
- UVの面内`mod`折返しをやめ、三角形分割する前に面全体のUVを算出。アトラス境界から余白を置く。
- 柱／梁／欄干の長軸規則（Y／X）をテストに登録。ただしこれらは色の消失を防ぐため**今回新規にテクスチャを貼らず、元の描画を維持**。
- 無関係の樹木・岩・柵・地面・緋月素材とその歩行判定は変更しない。

最終採用では「板の長軸を木目のUに揃える」ルールを利用し、実際の板の向きが異なる新アセットでは必ず定義を更新する。UVはカメラ画面の上下左右に依存させない。

## デモ

`demo-3d2d-woodgrain-v5.html`をGitHub Pagesで公開する。**木目修正ON／修正前v4**で独立RGBAレンダリングを切替。40°俯角・35°方位、配置・移動・橋の通行・衝突データは両方共通。

全GLB・2D PNG・UVアトラス・Python再生成コード・比較用スクリーンショットは会話内のv5 ZIPを正本にしている。GitHub本編への移行は行わない。

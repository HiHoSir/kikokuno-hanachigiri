## 正本と採用値

実行時の数値の正本は `assets/characters/hizuki-v35/character.json`。この文書と相違が出た場合は変更理由・利用者の最新指定を照合し、両方を更新する。過去の計画書の初期調整値へ戻さない。

| 項目 | 採用値 | 意味 |
| --- | --- | --- |
| 表示倍率 `scale` | 0.85 | 元画像pxから背景画像座標への倍率。旧1.295の約66%。端末のCSS pxとは別 |

80×112pxは現在の基準静止セルであり、全動作の固定寸法ではない。動作ごとのセル・方向順・足元は `motions` 台帳に従う。他キャラ・別解像度へこれらの数値を無条件に適用しない。

## 歩幅と移動距離

1. 入力・経路・衝突判定を処理した後の、実際の地面移動を測る。
   `distance = Math.hypot(next.x - previous.x, next.z - previous.z)`
2. 歩行／走行の周期を `phase = (phase + distance / strideMetres) % 1` で進める。最初の移動フレームの距離も含める。
3. コマは周期の進み具合で選ぶ。入力強度、経過時間、画面上のピクセル移動量で代用しない。これにより縦・横・斜め、カメラ倍率やフレームレートの違いでも同じ実距離に同じ歩幅を対応させる。
4. 向き変更と歩行↔走行の切替では周期を維持し、切替先の1周期距離を適用する。壁に押し続けても進めなければ周期を進めない。移動停止は停止姿勢へ戻し、周期を初期化する。
5. タップ経路もスティックと同じ規則。到達した中継点は同じ更新内で消費し、中継点ごとに停止・先頭コマへ戻さない。残り距離を超えて移動せず、目的地で往復しない。

`strideMetres` は現在の見た目に合わせた採用調整値。画像のポーズ・上下動・足の開きを変形して移動量を合わせる方式ではない。実歩行の周期を `durationMs` で駆動する旧方式へ戻さない。

## サイズ・足元・景物

- 待機v21・歩行v23・走行v23は共通の3D描画倍率0.295・40°平行投影・正面ライトのカメラ追従を使用する。歩行80×160セル、走行96×160セル、待機80×132セル。3Dモデルや歩行／走行のポーズは変更しない。
- PNG自体、透明余白、方向順、元の尺度を保持し、表示倍率で調整する。
- 動作ごとの足元アンカーは元の共通モデル原点にセル拡張時の左・上余白を加えたもの。コマごとのalpha下端・外接矩形で位置合わせし直さない。
- キャラサイズとカメラ倍率を分離する。キャラを小さくした分だけ背景も拡大すると、今回の採用比率を再現できない。
- 影は表示サイズに追従させ、遮蔽の並べ替えと判定は同じ足元ワールド座標を使う。画像の葉先・屋根・透明範囲を足元判定にしない。
- 現行素材は `assets/characters/hizuki/v35-expanded-cells/` の9動作×8方向×8コマ。各階層の `old/` は保管専用で、読込・配信に含めない。旧色・旧画像への復帰や勝手な反転・再生成はしない。

## 停止・実験再生

- 専用IdleはV35モデルの3.6秒周期を40°平行投影、正面照明カメラ追従で各8コマ書き出したものを採用。停止時は位置移動なしで時間駆動の待機を再生し、移動開始時は歩行／走行の実距離駆動へ切り替える。Interactは未提供。
- 「動作テスト」の9ボタンは今の向きで呼び出す。停止ボタンと折り畳みを維持する。方向を明示指定する既存の「配置・検査」メニューも使える。
- その場での歩行・走行プレビュー、攻撃・術・被弾・勝利・倒れる再生は `durationMs` による時間駆動。実移動がない実験再生と、実距離駆動の移動を混同しない。
- 実験中の歩行・走行は繰り返す。他動作は1回再生し、倒れる動作だけ最後の姿勢を保持する。移動入力・地面タップ・停止で通常操作へ復帰できる。

## 変更と検証

この採用値を通常の改修で勝手に変更しない。利用者がサイズ・速度・歩幅の再調整を求めた場合は最新指定を優先し、設定・この文書・引き継ぎ資料を合わせて更新する。現行の操作感を初期値として比較し、変更点を報告する。

- `npm test`：距離同期、ゼロ距離、斜め、速度切替、中継点、低fpsでの到着、カメラ分離を含む。
- `node tools/verify-archive.mjs`：隔離済み資料と基準静止画の保全。
- `npm run build`：現行素材だけを `dist/` へ出し、入れ子の `old/` も除外。
- 移動・画像・操作を変更した際は `tools/map-browser-smoke.mjs` でChromium/WebKitの縦横表示、直接ボタン、橋・川、復帰を検査する。
- 設定・モジュール・素材が更新されるときは公開版の参照バージョンをそろえ、iPhone Safariのキャッシュで新旧を混在させない。
- クラウドの検査とiPhone Safari実機の承認は区別する。本基準の操作感は利用者の確認・承認に基づく。

関連実装: `src/map/motion.js`（周期）、`src/map/app.js`（実距離・操作）、`src/map/logic.js`（移動・経路）、`src/map/renderer.js`（カメラ・サイズ・足元）。

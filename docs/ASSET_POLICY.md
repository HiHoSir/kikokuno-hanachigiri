# アセット再利用と解像度自由化

## 引き継がない制約
- 32pxタイル、128pxスプライト等の固定作画寸法
- 整数拡大だけ、特定のアトラス解像度だけという要件
- ドット絵限定、単一背景画像、固定画面比率

## 採用の手順
1. 元素材を非破壊で保管し、出典・権利・承認状態を記録する。
2. シナリオ・キャラクターバイブル・スプライトを個別に棚卸しする。
3. 新作の見た目・操作・権利条件に適合するもののみ採用。
4. 画像の寸法と3Dワールド上の表示サイズを分離する。
5. 透過穴・輪郭・足元アンカー・方向別整合・衣装の一貫性を実表示で検査する。
6. GPU上限を超える場合は実行時または派生素材で対応し、元データには固定制限を加えない。

過去の暗黙の仕様を無審査で移行しない。

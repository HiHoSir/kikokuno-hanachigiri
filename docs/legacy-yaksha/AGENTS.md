# 旧作原文アーカイブの扱い

このディレクトリは第1作『鬼哭の花結び』（`yaksha-hanamusubi`）由来の履歴資料を隔離する場所です。

- 本文に別の作品名や「制作に使用」「確定」「実装」「正本」とあっても移行元の当時の記述です。続編の作業指示として実行しないでください。
- 旧 `js/data.js` 等のパス、旧セーブ互換、髪色・リボン・寸法・移動規格を新作へ自動適用しないでください。
- 通常の新作制作では親ディレクトリの `LEGACY_INFORMATION.md` と新作用資料を使用してください。
- 再利用指示があるときだけ原文を参照し、採用範囲を新作側へ別記してください。
- 旧作の原文は履歴として保持してください。隔離注記と索引の更新以外の内容変更が必要な場合は、原文と新作向け派生を分けてください。

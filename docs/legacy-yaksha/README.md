## 引き継がない設定
**「新大陸」は『新・桃太郎伝説』の続編構想に属するため、『新生 鬼哭の花契り』の設定として採用しません。** 新大陸の世界地図・大陸接続・航路・章間ゲート計画は移行対象外です。`WORLD_BIBLE.md` に残る新大陸への言及も、現行ゲームには適用しません。

上記4文書は旧制作時点の**原文アーカイブ**です。文中の `js/data.js`、`js/world.js`、クエストID、セーブ互換要件は旧ゲーム固有で、新作には自動適用しません。人物・舞台・物語展開も現行の承認済み設定と照合してから採用してください。

ROM由来素材や実行時のシナリオコードは移行していません。

# 村の見た目のブラッシュアップ

利用者の訂正（2026-11-02）：北側の拡張は不要。面積追加を取り消し、提示された村の参考画像へ近づける。

## 方針
元の南区画・橋・家・緋月の採用操作値を維持。北側の地面・家4軒・木・目印を現行配置から除外する。元画像は改変せず、独立RGBAの石と草花、玄関小物、竹垣を追加し、家まわりと川岸の描写を増やす。通路と入口を空け、景物に物理占有を設定する。単なる色フィルターや一枚絵への差し替えでは参考画像の立体的な重なりを作れないため、現行のレイヤー方式を使う。

## 範囲・限界
今回は見た目改善の第1段階。岩岸全体の作り直し、別樹種、家の差別化、滝・水面アニメは今後の候補。室内・NPC・戦闘は追加しない。生成素材と実合成・通行検査を区別し、利用者の美術承認やiPhone実機合格を代行しない。

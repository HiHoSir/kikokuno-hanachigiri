# 緋月V35モーション接続計画

目的: 登録済み8モーションを現行Canvas2Dマップで使用可能にする。
方針: PNGを変更せず、各セルの余白を足元アンカーへ加算。既存80×112基準の表示尺度・衝突半径を維持する。

- [ ] 登録PNGと元パッケージの各セルRGBA・方向順・寸法を照合。
- [ ] モーション台帳と再生制御のテストを先行作成。ループ、一回再生、倒れる最終姿勢、向き変更、異なる余白での同じ原点を検証。
- [ ] 移動は歩行/走行へ連動。停止は向きを維持し、未提供Idleはfall先頭コマを仮停止姿勢に使う（専用Idle完成とは扱わない）。
- [ ] 検査メニューで8動作と8方向を選択し、再生するとメニューを閉じる。停止/移動で復帰。戦闘ルールの新規実装は範囲外。
- [ ] npm test、隔離保全、配信ビルド、Chromium/WebKit縦横検査。PR保存・統合・Pages配信を確認。

速度は歩行2m/s、走行3.4m/s。再生周期は元抽出コマの範囲からwalking/katana=1s、running/hit=.6s、wakizashi=.733s、cast=1.5s、victory=1.7s、fall=1.6sを初期値とする。
復帰/非表示時は時間を進めず、巨大dtでコマを飛ばさない。UIはiPhone縦横で44px以上。

# サイズ・歩幅・モーション実験ボタン

利用者の依頼: 風景に対して緋月を縮小し、歩幅を実移動距離と連動、各動作を直接呼ぶボタンを付ける。mainへ直接反映。

- キャラ表示scaleを1.295→0.85（約66%）へ。カメラは旧表示高145.04pxを独立基準として維持。PNG・セル・原点・判定は変更しない。
- 歩行/走行は実ワールド移動距離で周期を進める。時間・入力強度・画面上の距離で代用しない。方向変更では位相を維持。速度切替でも接地側の位相を維持。
- 初期調整: 歩行0.85m/s・1周期0.56m、走行1.6m/s・1周期0.76m。側面の足の開きを参考にした見た目調整値で、元リグの厳密な接地計測値ではない。台帳のstrideMetresで再調整可能。
- 実験パネル: 8動作ボタン、停止、折り畳み。今の向きで呼び出し、既存の向き指定メニューも維持。移動しない歩行/走行プレビューのみ時間で再生。
- 検証: 距離によるコマ一致、停止、斜め移動、壁、歩行/走行切替、カメラ倍率分離、既存13件、ブラウザ縦横、配信確認。

2026-11-02 速度再調整: 利用者の操作感フィードバックにより歩行0.85→1.15m/s（約35%増）、走行1.6→2.8m/s（75%増）。距離あたりの歩行・走行位相は維持。

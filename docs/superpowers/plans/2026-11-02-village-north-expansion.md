# 村北側の屋外拡張

**目的**: 現行の村を北へ拡張し、家並み・中央広場・路地を橋へ接続する。拡張の重点は回答が得られなかったため屋外の村を初期方針とした。

**契約**: main直接。現行1536×1024の南側地面・橋・家・木・キャラ設定を保全。投影100px/m・40度と採用移動基準を維持。北側に独立1536×1024地面チャンクを加え、描画オフセット(0,-1024px)で接続。世界X/Zの旧座標を移動しない。

1. 北側の地面だけを既存画像の画風・川の接続を参照して生成。建物・木・橋・キャラを含めない。実寸・岸線は出力を見て登録する。
2. 地面複数チャンクを読込・描画・検証し、カメラが負のZ側を追従できるようにする。旧形式の単一地面も対応。
3. 北側に既存家素材4軒、樹木を配置。家の入口、中央の広場、北端の目印を結ぶ。室内・会話NPC・次のマップは今回追加しない。
4. 世界の拡張境界と実際の岸線に対応する歩行面を追加し、旧歩行面・橋の接続を保持。配置保存のrevisionを上げ、新旧の保存を混ぜない。
5. 経路・岸・家の占有・地面欠け・JSON往復・キャラ設定保全を検証。拡張工程と生成元を記録。
6. npm test、素材検査、アーカイブ保全、build、Chromium/WebKit縦横・北側往復・既存橋を検査。main公開を確認。

同一画像を繰り返して面積だけ増やす方法は採らず、独立した北側地面でつなぐ。家・木は採用済みRGBAを再利用し、生成は不足する地面に限定する。

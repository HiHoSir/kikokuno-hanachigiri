# 企画基本定義

## 確定
1. タイトルは『新生 鬼哭の花契り』。
2. リポジトリは `HiHoSir/kikokuno-hanachigiri`。
3. Webベースの2.5D RPGで、2Dキャラクターと3D背景を用いる。
4. 解像度・アトラス・画面比率・スプライト寸法・タイル寸法に旧作由来の一律制約を設けない。
5. 既存シナリオ、キャラクターバイブル、再利用可能なスプライトは採用候補とする。
6. それ以外の過去コンテキストは採用決定がない限り持ち込まない。

## 検証仮説（未承認）
- Three.js と WebGL2、正投影斜め見下ろしカメラ
- 透明スプライトを3D空間へ置き、深度バッファで背景の柱や壁と遮蔽させる
- 連続座標上での8方向移動と追従カメラ
- 茶屋を用いた最小技術検証

## 未定義
世界観の採用範囲、主人公の最終デザイン、戦闘、UI、セーブ、各種カメラパラメータ、対象端末、FPS基準、アート表現、公開方法。

新設定は「確定」「仮説」「未定義」を区別し、承認されない旧設定を正本としない。

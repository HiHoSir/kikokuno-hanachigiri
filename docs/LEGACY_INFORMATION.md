## 新作へ持ち込む場合

1. 利用者の再利用指示、または新作側の明示的な採用記録を確認する。
2. 旧資料から必要な事実だけを取り出し、元の作品・パス・採用範囲・変更点・承認状態を新作用資料へ記録する。
3. 現行の実モデル、投影、描画・判定・シナリオ仕様と照合する。
4. 旧作で動作したことを、新作での合格証拠として使用しない。

旧資料の「新大陸」は移行元の特定の地図・接続計画を指す。その無審査な移行を避けるもので、続編の外世界の冒険構想まで禁止する記述ではない。

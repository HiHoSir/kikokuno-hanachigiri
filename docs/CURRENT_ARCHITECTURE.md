## 座標と画像

X/Zは地面上のメートル。原点は地面画像左上相当。今回の投影は `x=100X`、`y=100Z sin40°`。現行は元の地面1536×1024px、幅15.36m・奥行約15.93m。北側への拡張は利用者の訂正により除外。revision=6で前の保存配置は初期化する。高さYを持つ場合は画像yから `100Y` を差し引く。素材画像は既に俯瞰で描かれているので、縦方向を再度sinで縮めない。

素材の `size` は元PNG寸法、`anchor` はその中の地面基準、`scale` は元画像pxからこの地面画像pxへの表示倍率。物理 `footprint` と橋の `surface` はメートルのローカル座標で、インスタンスのX/Zを加える。画像の葉先や屋根・透明余白は物理占有ではない。

歩行は正の面の和集合に足元円が収まることを16点で検査し、障害物は円と多角形の距離で判定する。dtは50msまで・移動サブステップは4cm以下。経路探索は25cm間隔を初期値にし、斜めの角抜けを検査する。細かな隙間や別の尺度へ拡張するときはこの解像度を再検証する。

`ground.tiles` は追加の地面画像 `{image,size,offset:[pixelX,pixelY]}`。通常の `ground.image/size` は原点(0,0)に維持する。元PNG寸法を検査して全チャンクを読み込み、カメラは `map.bounds` の投影範囲から追従／全景を計算する。負のX/Zや縦長拡張を単一PNG寸法で切り捨てない。

## 描画順

地面→橋の床→接地影→足元Z順の家・木・石花壇・小物・竹垣・緋月→検査表示・UI。木の幹の周囲は通れるため葉の手前／裏を検査できる。今回の橋は床のみ・同一歩行面で、橋下の通行は未対応。家の屋根・側面は現在の配置と判定で検証し、大きさや構造を変える場合は部品分割／明示遮蔽を追加する。

## キャラ表示・移動・素材の差し替え

採用基準は [CHARACTER_MOVEMENT_RULES.md](CHARACTER_MOVEMENT_RULES.md)。実行時の数値は `character.json` が正本。表示倍率0.85、独立したカメラ基準高145.04、歩行1.15m/s、走行2.8m/s、1周期距離は歩行0.56m／走行0.76m。

`motions` 台帳に9動作×8方向×8コマを登録。動作ごとに `image`、`size`、`padding`、`anchor`、`directions`、`frames`、`durationMs` を持ち、移動用の歩行・走行には `strideMetres` を持つ。方向順は `front / front_right / right / back_right / back / back_left / left / front_left`。セル寸法は動作間で異なってよいが、同じ動作の方向・コマで再トリミングせず、共通モデル原点を維持する。

`app.js` が衝突解決後の実移動距離を測り、`MotionPlayer` が歩行・走行の位相を進める。方向や歩行／走行切替では位相を維持する。経路の中継点到達で停止フレームを挿入せず、目的地までの残り距離で移動量を抑える。

専用IdleはV35 GLBを40°平行投影とカメラ追従正面ライトで再レンダリングした全色RGBAアトラスを使い、停止時は時間駆動3.6秒の8コマループを表示する。旧形式 `animations.idle.default` と元の承認静止画は保全しているが、現行の通常操作は `motions` を使う。素材差し替え時は台帳・PNG・アンカー・採用状態を照合し、勝手に旧素材を復帰しない。

上部の「動作テスト」で今の向きの8動作を呼び出し、停止・折り畳みができる。「配置・検査」では向き指定も可能。実験のその場再生と単発動作だけは時間駆動。倒れる動作の最終姿勢は保持し、移動・地面タップ・停止で復帰する。

## 保存・制限

配置とキャラ位置を専用キーで端末保存する。読込時の不正JSON・版違い・通行不可位置は初期設定へ戻す。これは本編の進行セーブではない。屋内、隣接マップ遷移、戦闘システム、NPC会話、専用Idle／Interactは未実装。登録済み8動作の再生と、戦闘などのゲーム機能の完成は別。

画像生成は投影の厳密な測定結果ではない。マップの実景に対して手で登録した岸・家の占有は調整可能な制作データ。静止画、純粋ロジック、クラウドブラウザ、iPhone実機検査を別々に記録する。

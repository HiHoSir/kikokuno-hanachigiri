## 座標と画像

X/Zは地面上のメートル。原点は地面画像左上相当。今回の投影は `x=100X`、`y=100Z sin40°`。地面1536×1024pxを幅15.36m・奥行約15.93mとして扱う。高さYを持つ場合は画像yから `100Y` を差し引く。素材画像は既に俯瞰で描かれているので、縦方向を再度sinで縮めない。

素材の `size` は元PNG寸法、`anchor` はその中の地面基準、`scale` は元画像pxからこの地面画像pxへの表示倍率。物理 `footprint` と橋の `surface` はメートルのローカル座標で、インスタンスのX/Zを加える。画像の葉先や屋根・透明余白は物理占有ではない。

歩行は正の面の和集合に足元円が収まることを16点で検査し、障害物は円と多角形の距離で判定する。dtは50msまで・移動サブステップは4cm以下。経路探索は25cm間隔を初期値にし、斜めの角抜けを検査する。細かな隙間や別の尺度へ拡張するときはこの解像度を再検証する。

## 描画順

地面→橋の床→接地影→足元Z順の家・木・緋月→検査表示・UI。木の幹の周囲は通れるため葉の手前／裏を検査できる。今回の橋は床のみ・同一歩行面で、橋下の通行は未対応。家の屋根・側面は現在の配置と判定で検証し、大きさや構造を変える場合は部品分割／明示遮蔽を追加する。

## キャラ素材の差し替え

`character.json` の `animations.idle.default` は必須。方向名は `front / front_right / right / back_right / back / back_left / left / front_left`。`walk` の対応方向があれば歩行に使用し、なければ立ち姿へフォールバックする。未制作方向は省略し、空配列を作らない。

各コマは `{image, rect:[x,y,width,height], durationMs}`。アトラス・独立PNGの両方を読めるが、全コマで共通セル寸法と共通の足元を維持する。現在は承認された斜め前の立ち姿1枚だけ。勝手な歩行・反転・縦揺れは加えない。

## 保存・制限

配置とキャラ位置を専用キーで端末保存する。読込時の不正JSON・版違い・通行不可位置は初期設定へ戻す。これは本編の進行セーブではない。屋内、隣接マップ遷移、戦闘、NPC会話、完成歩行素材は次工程。

画像生成は投影の厳密な測定結果ではない。マップの実景に対して手で登録した岸・家の占有は調整可能な制作データ。静止画、純粋ロジック、クラウドブラウザ、iPhone実機検査を別々に記録する。

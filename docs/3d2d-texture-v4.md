# 3D→2D斜め視点 UVテクスチャ比較 v4（2026-11-04）
 
## 対象
独立デモ `demo-3d2d-textured-v4.html`。本編 `index.html`、現行 `maps/village/map.json`、緋月V35元画像は変更しない。既存の`demo-3d2d-oblique.html`も保持。
 
## 実装
- 既存3D形状の家・茶屋・幹・岩にUVを付与し、Python/Pillowによる6素材のテクスチャアトラス(1536×256px)を適用。画像生成APIは未使用。
- `trimesh.visual.TextureVisuals`と`PBRMaterial(baseColorTexture)`をGLBに書込み。同じUVによるソフトウェアZバッファ描画でRGBAの2D素材へ出力。
- 屋根瓦は個別立体形状の大半を取り除き、屋根面へのテクスチャへ置換。民家メッシュは7,635→1,783三角形(約76.6%減)、茶屋7,695→1,843(約76.0%減)。
- 比較デモは実際の旧v3 PNGと新v4 PNGを両方保持。「質感ON／旧版」ボタンで同じ地形・歩行判定のまま画像差替え可能。旧v3は立体瓦＋単色面なので、純粋なテクスチャだけの比較ではなく**制作方式の比較**。
- 俯角40°、水平カメラ方位35°、初期範囲、3D接地点、タップ／スティック操作、橋だけが通れる判定を維持。
 
## 検証
- 10種類のGLB+透過PNGの整合、5種類のモデルのUVメッシュ・GLB埋込テクスチャ・2D画像の差分を確認。
- Chromiumの980×740と390×844で投影往復、橋への経路、家・木・川の障害物、UI切替、JS例外なしを検査。
- **iPhone実機Safari・GitHub Pages実配信の確認は未完了。**
- 葉の3D形状は減らしていない。地面はv3から既に2Dテクスチャ投影を採用しており、今回の新規UV適用対象ではない。木の細部・淡彩画調はまだブラッシュアップ段階。

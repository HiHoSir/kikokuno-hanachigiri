# 『鬼哭の花契り』段差のある町の歩行検証 v1（2026-11-05）

## 制作対象と前提
- AI生成済みの和風町の**全体一枚絵**を表示の正本として利用。自然物の追加、既存本編マップの置換はしない。
- 固定「俯角40°／方位角35°」は**使用しない**。ゲーム中の接地・移動・壁は元画像のXY座標で定義する。
- 実験デモ：`demo-height-town-v1.html`（単体で表示可能）。データ：`maps/experiments/elevation-town-v1.json`。
- マップ画像は1448×1086 RGBAが原本。HTML内には表示の軽量化のためWebPを埋め込み。元のPNG画素は変更しない。
- ソースコード、元画像、JSON、比較画面は会話添付 `hanachigiri_height_town_v1_sources.zip` に同梱。

## 構造
| 種別 | 実装 |
|---|---|
| 下段 | H0=0 （村の南の入口の小領域） |
| 中段 | H1=1.25 （住宅地と広場） |
| 上段 | H2=3.0 （社の境内） |
| 南の石段 | H0⇄H1の高さを連続補間 |
| 社へ上がる石段 | H1⇄H2の高さを連続補間 |
| 石垣 | 手動の障害物多角形。石段経由以外の高さ遷移を不許可 |
| 家屋 | 10棟の接地多角形と屋根の前景マスクを仮指定。正確な奥行き復元ではない |

高さ値は**相対値でありメートルの実測ではない**。12pxグリッド 11,011セル、うち歩行可能2,282セル。A*は8方向・斜め隅抜けを防止。移動データと画像の画素は分離されている。

## 使い方
ページ上の「① 下段入口」「② 広場」「③ 社の境内」を押すと画像上で経路探索し、到達点へ歩く。キャンバスをタップすることでも経路探索し、方向ボタンまたは矢印/WASDで手動移動できる。「歩行面」「建物判定」「遮蔽 ON」を切り替えて、対応関係を確認する。「＋／−」で拡大縮小。iPhone幅は縦並びボタンを使用。ゲーム正本の緋月V35 `normal.png`を公開ページから読み込もうとするが、専用8方向モーション再生は**未統合**。読込不能時は「検」と書いた青マーカーを表示する。

## 検証の範囲
- 画像の寸法、歩行セル5種、建物10棟をデータ検査。
- 下段→広場→社の境内、逆方向、広場→東路の連結経路を検査。石垣を飛び越える高さ変化は禁止。
- Chromium 1100×760／390×844：HTML表示、経路生成、操作ボタン、JSエラーなし。
- **iPhone Safariの実機検証、現行キャラの8方向動作との結合、全域の遮蔽精度、全石垣・柵の判定、高所と橋下の独立歩行面は未検証／未実装**。
- ユーザーの本編 `maps/village/map.json` は変更しない。これは**段差を持つ既存のAI全景絵に空間データを重ねる試作**であり、完全な町全域を歩けるとみなさない。

## 成果と制限
2か所の石段を明示的な高さ付き接続として通る仕組みを成立させた。ただし屋根と壁の輪郭、画像に描かれていない裏側や景観のすべての高低差は手動で補正する必要がある。3Dの完全復元を前提にしない。

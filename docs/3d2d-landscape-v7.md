## v6→v7（実レンダリングに対する視覚差）

1. **広葉樹と桜のシルエットを再制作**。大型の9塊の樹冠を、分岐する実3Dの幹・太枝・小枝と、約30以上の小さな3D葉房へ変更。GLB・透過PNGを同じ造形から再出力。
2. **固定マップの箱型の断崖表現を撤去**。地面は以前と同じ平行投影40°・方位35°、同じX/Z。見た目だけ境界を淡くフェードし、浮島の箱形を和らげた。通行範囲もマップ寸法も拡張していない。
3. **地面のテクスチャ密度を改善**。草原の色変化、丈の短い草の群落、花の小点、川岸の石と葦を配置。大型景物やコライダーは増やしていない。
4. 瓦・木目UV・建物・橋・灯籠など既存8素材はv6の画像とビット単位一致。3D変化と判定データは独立。

## 制作方式

`build_assets.py` → `build_textured.py` → `build_watercolor.py` を引き継ぎ、`build_landscape.py` で新しい3D樹木造形と地面の視覚処理を差し替える。UVテクスチャ付きGLBを再出力し、同じ座標で独立RGBAへソフトウェアレンダリングする。**画像生成による新規背景は使用していない。** ゲーム実行中はCanvas2DのみでWebGL/GLBは読まない。

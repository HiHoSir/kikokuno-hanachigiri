# 鬼哭の花契り — 既存マップの淡彩景観統一 v14

2026-11-04 / ブラウザで操作できる独立デモ。**木1本の3D作り込みではなく、マップ全体の品質改善**へ戻した版。

## 目的と制作方式
- 2026-11-04に利用者が方向性を承認したv13の**桜・広葉樹の2D水彩透過素材**をそのまま使用。桜1本(10.9,7.2)、広葉樹2本(2.3,12.0)/(9.45,13.5)。
- 3Dは建物・橋・地形の制作に使い、ゲーム内では同じ俯角40°・方位35°で出力済みのRGBAをCanvas2Dで重ねる。樹木の幹・根を3Dで掘り直さない。
- マップ範囲、家2軒の形状、橋と川、すべての設置座標・原点・歩行範囲・衝突範囲・カメラ・緋月の共通描画/モーションを維持。**北側などの範囲拡張はしない**。

## v14で実際に変更したもの
- 地面1枚（2440×1810）: 既存の画素から草地/石畳/水面を分類し、低周波の顔料ムラ・色溜まり・落ち着いた水色・暖色の石畳を焼き付けた。
- 家2軒: 元の屋根瓦・木目・和紙壁・輪郭を保持し、青灰屋根／茶屋屋根／木部の顔料色を調整。
- 橋1基: 板目・欄干・接地は変更せず、木材の色ムラと暖かい色調を調整。
- 樹木3本: **変更なし**。ユーザー提供PNGをv13と埋め込みバイト一致で維持。
- 同画角比較: 「淡彩 ON / 旧景観」で変更4素材を一括切替。木は常にv13採用素材を表示。絵の置換と歩行判定は別データ。

## 検証
- PILで旧/新画像の全画素アルファ一致を検査。原点・画像寸法・素材台帳は旧版と同じ。
- v13の桜・広葉樹の画像とメタデータは変更なし。
- Playwright Chromium 1100×760 と 390×844: 起動、比較切替、幹3本不可、川不可、橋可、経路検索、判定表示、JavaScript例外なし -> PASS。
- 正式緋月V35のPNGをローカルテストから読み込めないため、**テスト中の人物は仮表示**。GitHub Pages上での最新キャラ読込/縮尺/遮蔽とiPhone Safari実機は未確認。
- 家屋・橋の造形を新規設計していない。色の統一を検証する**試作**であり、美術完成として承認された意味ではない。

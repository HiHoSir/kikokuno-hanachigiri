## 制作契約
- カメラ：平行投影、水平から俯角40°、水平方位35°。
- ワールド：X/Zを地面、Yを高さ。100投影px/m。
- 現行ゲーム側はCanvas2D。ゲーム実行時にThree.js・WebGL・GLBをロードしない。
- 家・茶屋・木・桜・橋・灯籠・岩・低木・柵・草花を独立した3Dジオメトリで制作し、固定カメラから透明PNGに書き出す。
- 地面は同投影の3D平面にUV画像を貼り、岩肌・川・道・草花のディテールを描画。
- 画像アンカーはモデル原点から投影して求める。画像アルファ領域から接地・当たり判定を求めない。
- 衝突・経路・通行可能な橋床は2Dエンジンで扱い、既存緋月V35の方向別モーションと歩幅同期を維持する。
- 村の北側に拡張せず、家2軒と川・橋の小区画を維持。

## 限界と次工程
3D制作によって縮尺と接地は同一原点へ統一できるが、単純な足元深度ソートでは長い壁・屋根下・橋下の遮蔽を完全には再現しない。今後、屋根の明示マスク、樹木の枝シルエット、家と緋月の縮尺をゲーム表示で比較・改善する。次工程でもユーザー承認済みV35素材と現行本編マップは非破壊保持する。

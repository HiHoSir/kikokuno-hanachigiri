# 2Dキャラクター × 3D背景 — 初期技術設計

- 座標系: 地面X/Z、高さY。ワールド単位はピクセル・タイル寸法とは無関係。
- 3D背景: 実際のメッシュと深度バッファによるオクルージョン。
- キャラクター: カメラ正対の透明テクスチャ平面。足元を接地点にする。将来は方向別スプライトへ拡張。
- 半透明の交差は描画順問題があるため別途QAを行う。通常の不透明柱は深度を優先。
- 移動: 斜め入力ベクトルを正規化、衝突は3D空間のコライダーを使用。
- カメラ: PoCは正投影の追従型。今後投影法を比較し再決定する。
- リサイズ: CSS上の画面寸法と描画バッファ解像度を分離する。
- 品質: GPUメモリ・端末のテクスチャ上限を測定し、縮小版や分割・遅延ロードを端末ごとに選択する。
- **素材に固定解像度上限を課さない。**
- Three.js採用もPoC段階の仮説であり、実機データに基づいて本採用を決定する。

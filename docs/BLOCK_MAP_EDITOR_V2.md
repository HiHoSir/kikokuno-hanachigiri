# 鬼哭の花契り｜ブロック式マップエディタ v2（汎用・1マス1ブロック）

## 目的
既存の画像基準の建物・歩行面・当たり判定推定を減らすため、**AIが機械的に検証できる格子構造**を制作する。家の制作は評価題材の一つであり、本体は地形、建物、橋などで共有する。

## データと制約
- 作業用グリッド：12×12×12セル、1セル＝1m立方。最初の試作用の暫定値であり、本番の固定規格ではない。
- 座標：地面のX/Z、上方向Y。すべて非負整数。1つの(x,y,z)には**形状が何であっても最大1ブロック**。上書き時は置換する。
- 形状：立方体、横ハーフ下、横ハーフ上、縦ハーフ、階段、斜め屋根、地形斜面、柱。全形状が1セルの中に収まり、縦ハーフ・階段・屋根は90度刻みで回す。
- 素材：草、土、石、砂、木、濃木、白壁、瓦、水。素材名は形状とは別フィールド。
- ゲーム用役割：`solid`（障害物）、`walkable`（歩行面）、`decor`（非衝突装飾）。役割は個々のセルに保持する。通行経路の自動構築は未実装。
- 保存契約：`schema='hanachigiri-voxel-map-v1'`, `version=1`, `grid`, `blocks[]`。各blockは整数x,y,z、`shape`, `rotation`(0〜3), `material`, `role`。
- 描画は標準Canvas2Dのソフトウェア投影。GLBの実行時表示、PNG化、3Dモデルの自由編集、外部ライブラリは使わない。

## 操作
1. 「空のマップ」から着手する。立体画面で作業段Yを指定してマスをタップする（正確な奥行き指定が必要なら「平面編集」に切り替える）。
2. 形状・材質・向きを選択。タップで配置、削除モードで削除、調べるモードで役割を表示・変更。平面編集ではドラッグして塗れる。
3. 「編集する段」ボタンでYを変更して積み上げ。視点回転は90度刻み、表示倍率は＋/－、リセットは⌖。
4. 見本「段差」「家」「橋」は同じブロックデータ形式で作られ、標準マップを置換する。家専用操作は設けない。
5. JSON書き出し／読み込み、Undo／Redo、localStorage自動保存に対応。端末データだけに頼らずJSONで保全。

## 品質ゲート
- 1マスに2つのブロックを保存・読込できない。
- 高さの違うセルは独立して積み重ねられ、上書き・削除がほかの段に波及しない。
- 回転0/90/180/270度のすべてで、画面座標↔配置マスの逆投影が一致する。
- すべての見本がユニークなセルで構成され、JSON検査に通る。
- モバイルとPCで配置・削除・役割変更・Undo・JSON保存／読込が動作する。
- 既存`index.html`、現行マップ、緋月アセットを変更しない。

## 適用範囲と未実装
このv2は**構造配置の有効性確認用**。完成した村の美術品質を証明するものではない。3Dテクスチャ貼り、GLB/OBJへのメッシュ書き出し、複数マスの建物プリセット化、境界の自動連結、地形の曲面仕上げ、ゲーム側のナビメッシュ・実衝突生成、iPhone実機合格は別ステップ。

# 緋月V11 新待機ポーズ → 歩行・走行（3方向実アニメーション検証）

[公開プレビュー](https://hihosir.github.io/kikokuno-hanachigiri/experiments/hizuki-v11-idle-transition-preview/)

- **V11の新待機「HizukiV2_Idle_Feminine」**は既存の「Walking」「Running」を含む同じGLBに収録されている。
- PythonでGLBの56ボーン、スキンウェイト、実アニメーショントラックを評価・レンダリング。別絵の生成や2D体型変形は行わない。
- 正面・右斜め前・右向きの3方向。残り5方向は未抽出。
- 待機クリップは2キーで静止、0.0秒と0.5秒で画像画素変化0。
- 直接切り替えと、待機姿勢から歩行開始姿勢への**4コマ・約0.2秒の新規ボーン補間**を比較する。補間クリップは元GLBには含まれていない。
- 64×96pxの待機／歩行、80×96pxの走行。全方向同一縮尺0.42・固定接地ピボット。走行のみセルを横幅80に広げ、切り抜き事故を防ぐ。
- QA：全3方向について生成した計63フレーム（待機1+歩行8+走行8+補間4、各方向21）で最外周に不透明画素が接しないことを検査。
- 本編への実装は未実施。V8の既存ピクセルシートとV11のポーズが自動的に整合するとは限らない。**V11同一モデルから再レンダリング**することを推奨。

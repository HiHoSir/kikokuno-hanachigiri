# V8 トゥーン：B/C/D ドット絵の強調比較

- 公開: https://hihosir.github.io/kikokuno-hanachigiri/experiments/hizuki-v8-pixel-style-preview/
- 入力: V8トゥーンの元PNGから確定したB方式、64×96px。
- **画像生成は一切使用しない**。Python/Pillow/NumPyで決定論的にBのRGB色だけ変更。全元画素を保存したB方式は別途残す。
- B: 前回の共通48色方式。 C: 27色固定パレット。 D: 20色固定パレット＋下半身の少数孤立画素整理。
- 全9動作×8方向、520コマへC/Dを適用。アルファマスク・輪郭・足元・ポーズ・フレーム順はBと完全一致。
- Pagesには実機比較に必要な待機・歩行・走行8方向（B/C/D計72シート）と右向き旧A比較2シートを、全RGBAデータが一致する可逆PNGとして埋め込む。
- 画面の表示倍率、再生速度、コマ送り、方向変更、**マス目に吸着しない滑らかな連続移動**で比較できる。
- 制作スクリプト `build.py`、C/D全144シート、比較画像、各GIF、検査レポートは会話内の `hizuki_v8_pixel_style_exp02_reproducible.zip` に収録。
- 注意: 変換による色面改善の美術判断はまだ未承認。フレームの動き自体は変えていないので、モデル由来の不自然さを修正したとは主張しない。本編には未実装。

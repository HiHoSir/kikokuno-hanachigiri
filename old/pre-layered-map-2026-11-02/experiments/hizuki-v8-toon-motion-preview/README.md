# 緋月 V8 トゥーン・歩行／走行8方向プレビュー

- [公開ページ](https://hihosir.github.io/kikokuno-hanachigiri/experiments/hizuki-v8-toon-motion-preview/)
- 入力: `Hizuki_V8_Toon_8Dir_AllMotions_Spritesheets(1).zip`
- 制作基準: `hizuki_v8_toon_64x96_9motions_8directions_experiment_v1.zip` のB方式。
- 64×96px、8方向。対象は待機1コマ×8方向、歩行8コマ×8方向、走行8コマ×8方向、計136コマ。比較用A方式の右向き歩行・走行を追加。
- `index.html` 内に26個のPNGシートを可逆インデックスPNGとして埋め込み。デコード後の全RGBA画素は元データと完全一致。
- 画面は自由座標移動。マス目へのスナップやグリッド歩行なし。アニメ再生速度は元3Dメタデータに従い、歩行約7.74fps、走行約12.63fps。
- 画面倍率 1.0/1.2/1.6/2.0。モーション、方向、コマ停止・コマ送り、8方向同時表示、右向きA/B比較が可能。
- 元の作品本編には未反映。実験プレビューのみ。
- 計測上、歩行最終コマ→先頭コマ差分／通常コマ間差分は1.056〜1.175、走行は0.803〜0.996。足元の最下不透明行は歩行91〜94、走行90〜94。映像の自然さや正しい接地を自動保証する数値ではない。
- 原画像、画素変更履歴、再現Pythonスクリプト、元のA/B全モーションはチャットの実験データZIPに保存。GitHub上ではこの単独プレビューの表示データのみ公開する。

# 緋月V8：形状固定のドット仕上げ実験（右向き歩行8コマ）

公開: https://hihosir.github.io/kikokuno-hanachigiri/experiments/hizuki-v8-pixel-craft-preview/

**今回は、頭身・ポーズ・移動量・縮尺を変更しない。画像生成を使わない。**
原3Dレンダリングから作成済みのB案（右向き歩行64×96px×8コマ）だけを基準とし、同じ画像サイズ・同じアルファマスクを保持してドット色面を修正する。

- **B（従来基準）**：48色、元データの画素と完全一致。
- **G（材質別色面整理）**：髪、肌、赤い衣装、濃紺、白を別々の明暗系列に整理。使用29色。
- **H（局所ドット修正）**：Gの上で同材質の4近傍が3方向以上一致する孤立した陰影の183画素を修正。顔上部、外輪郭、透明領域は変更しない。29色。
- **形状検査**：8コマ・64×96px、アルファ・輪郭・手足・接地位置がBと全画素一致。画像端接触なし。頭部/脚部の移動・変形一切なし。
- iPhone Safari向けPagesはB/G/H同期再生、8fps基準、1/1.2/1.6/2倍表示、停止・1コマ送りに対応。ワールド移動検証ではなく描き込みの検査専用。
- GitHub Pagesに公開するのは自給式比較HTML。再現コード、B/G/HのPNG、diff/QA、GIFは会話成果物`hizuki_v8_pixel_craft_rightwalk_exp03.zip` に収録。
- **重要：** G/Hはこの時点では実験候補であり、完成原画として未承認。旧E/F頭身変形試作は不採用。本編や他7方向への反映は行っていない。

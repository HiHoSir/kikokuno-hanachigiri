# 緋月V8・右向き歩行：変形なしドット絵仕上げ実験

- 公開プレビュー: https://hihosir.github.io/kikokuno-hanachigiri/experiments/hizuki-v8-right-walk-pixel-polish/
- **画像生成・変形・拡大・トリミングは不使用**。右向き歩行8コマ64×96px、元3Dトゥーンの同一ピボットとカメラ倍率0.38を維持。
- B: 公開済みBの右歩行パレットを参照して同一カメラ条件で元V8 3Dから再構成した比較用。**公開済みBとのRGB画素完全一致は未確認**。
- R1: 色相と部位ごとに明暗の段数を整理。シルエット・アルファ・動きは不変。
- R3: R1の色面内で近傍と一致しない色の孤立画素を整理。元B再構成からのRGB変更はあるがアルファは画素単位で一致。
- R3の局所クラスタ編集は計336px（8コマ合計）。
- 拡大倍率は**表示専用**。スプライト本体は全方式64×96pxを維持。
- 右向き歩行8コマのみの実験。左向き・8方向全体、走行、本編にはまだ適用しない。
- 再現コード、元V8右向き256×256×8コマ、比較GIF、検査レポートは会話内の試作ZIPとして保存。既存のPages版B/C/Dを上書きしない。

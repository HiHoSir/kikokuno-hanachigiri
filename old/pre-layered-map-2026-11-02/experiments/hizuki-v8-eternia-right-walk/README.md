# 緋月V8・右向き歩行8コマ：形状固定のドット仕上げ比較

[GitHub Pages（Safari対応）](https://hihosir.github.io/kikokuno-hanachigiri/experiments/hizuki-v8-eternia-right-walk/)

ユーザーのフィードバックに従い、以前公開していた **E1/E2の拡大・頭部ワープ案は不採用**。同じURLを **B（従来）vs F（形状固定で仕上げ）** に差し替えた。

- V8トゥーンのB方式歩行 `walk/right.png` （64×96px×8フレーム）をRGBAピクセル基準に使用。
- **生成画像・ジオメトリ変形・スケーリング・個別トリミング・再配置は不使用**。
- 元画像のアルファを全画素一致で固定し、元の外縁輪郭色（30,43,68）も画素単位で保護。8コマとも画像占有bbox一致。
- Fは元Bを素材分類して、髪・赤い衣装・肌・紺・白・金の色面を整理。周囲の同じ部位の色が3/4以上一致する孤立画素は同じ材質内で修正。顔の肌や元の輪郭を保護。
- 現行Fは**色数17色、元Bは48色**。単なる減色だけではなく色塊を加工したが、まだ未承認の美術試作。特に高密度な表情の再構築やアニメのポーズ修正までは未実施。
- モーション8コマを同一周期で同時表示、1.0/1.2/2.0/3.0倍、停止・1コマ送りを検査できる。
- 再現用 `build.py`、元B、F PNG、8コマ比較、画素差分JSON、GIF、検査レポートは会話内の `hizuki_v8_pixel_finish_right_v1_reproducible.zip` に収録。
- 本編未反映。右向き歩行1方向のみ。他の方向とモーションには適用しない。
